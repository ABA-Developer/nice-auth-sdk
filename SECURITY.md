# Kebijakan keamanan / Security policy

## Melaporkan celah

Jangan membuka issue publik untuk celah keamanan. Laporkan lewat **Security → Report a vulnerability** di repo ini (GitHub private vulnerability reporting). Sertakan versi SDK, langkah untuk mengulanginya, dan dampaknya. Jangan menyertakan API key, client secret, atau token yang masih berlaku.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Report it through **Security → Report a vulnerability** in this repository (GitHub private vulnerability reporting). Include the SDK version, the steps to reproduce it, and the impact. Do not include an API key, a client secret, or a token that is still valid.

## Versi yang didukung / Supported versions

Perbaikan keamanan diterbitkan untuk versi minor terbaru. / Security fixes are released for the latest minor version.
